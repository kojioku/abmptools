# 参照出力を差し替えた記録

このディレクトリは、リファクタ前の出力を凍結したもの。**振る舞いを意図的に
変えたときだけ**差し替える。差し替えたら、何がどう変わったかをここに書く。
書かずに差し替えると、次に落ちたときに「直したのか壊したのか」が分からなくなる。

---

## 2026-09-12 — `gro2udf` の 5 件と `udf2gro` の熱浴・圧力浴

いずれもこのブランチで意図的に変えたもの。差分は下記だけで、それ以外は
1 バイトも動いていない。

### `udf2gro/test.mdp`

| | 前 | 後 |
|---|---|---|
| `tau_t` | 1.5373204281117965 | **0.6283202517094353** |
| `tau_p` | 2.0 | **5.579894048988075** |

`tau_t` は `Q = g·k_B·T·τ²` から `τ` を戻す式に `g·k_B` が無く、系のサイズと
ともに増大していた。`tau_p` は `Cell_Mass` からの換算の係数が 3 か所ずれて
いて、下限 2.0 に丸められていた。`test.gro` は無変更、`test.top` は
`; input:` の絶対パスだけ（テストが正規化する）。

### `gro2udf_udf_gro_mode/test_groout.udf`

静的セルとレコードのセルが食い違っていた。

```
テンプレート test.udf の静的セル : 14.8011328235642 A   (MD 前の箱)
入力 gro の第 1 フレーム         : 14.8011 A

前  静的 14.8011328235642 / レコード 14.8011   <- 食い違う
後  静的 14.8011          / レコード 14.8011
```

静的側を読む下流では、**座標は新しい箱・セルは古い箱**になり、実行時に
セルが inf に飛んでいた。

### `gro2udf_from_top_mode/fromtop_out.udf`

差分 154 行。内訳は 5 件。

| 差分 | 何を直したか |
|---|---|
| `{100,0,0,0,0}` → `{100,1,0,1,0}` | `Dynamics_Conditions.Moment`。`--nh-dof 3N-3` を既定にしたので `comm-mode = Linear` に対応させた |
| `{0.0}` → `{1562.16}` | NPT 系のアルゴリズムにも `Q` と `Cell_Mass` を書く。空だと NPT に切り替えた瞬間に `tau_t = 0` になる |
| 静的セル `100.0` → `14.8011` | 同梱テンプレートの既定 100 A 立方が残っていた |
| `"ca-ca-0"` → `"ca-ca"` | ポテンシャル名の連番を、衝突したときだけ付ける |
| `[]` → `[{"SCNB","0.5"}{"SCEE","0.8333333"}]` | Amber 二面角の 1-4 スケーリング。空だと下流が 1-4 の扱いを決められない |
